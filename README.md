  Competitive Programming – Learning Summary (Week 1 to Week 4)

 What I’ve Learned So Far

 Problem-Solving Techniques
1. Learned how to use "Greedy Algorithms" by picking the best choice at every step (like in activity selection or coin problems).
2. Practiced using "Two Pointers" and "Sliding Window" to solve problems with ranges or subarrays.
3. Used "Prefix Sums" to quickly find the sum of elements between two positions in an array.
4. Got better at using "Binary Search", both the regular kind and the type where we search for the answer itself.
5. Learned different "Sorting Techniques", including how to sort in custom ways using C++.

Data Structures
1. Worked with "Vectors and Arrays", and used C++ STL functions to make coding easier.
2. Used "Sets and Maps" to keep track of unique elements or pairs of values.
3. Practiced problems using Stacks and Queues", like finding the next greater element.
4. Learned how "Priority Queues" work and used them in greedy and shortest path problems.

Dynamic Programming (DP)

 Solved some basic DP problems like:
    - Fibonacci numbers using memoization
    - 0/1 Knapsack
    - Longest Increasing Subsequence (LIS)
    - Counting paths in a grid

  Other Important Things I Learned

1. Learned how to handle tricky test cases like empty input, big values, and edge situations.

2. Got better at **debugging** by printing values and checking small examples to find what’s wrong.

3. Started doing a **dry run** on simple test cases before submitting, to make sure the logic works.

4. Learned to notice when my code is too slow and how to improve it to run faster.
